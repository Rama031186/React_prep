# React Cheat Sheet — Static Website

A standalone HTML/CSS/JavaScript recreation inspired by the referenced React interview guide.

## Files
- `index.html` — page structure and guide content
- `style.css` — responsive styling and light/dark themes
- `script.js` — topic filtering, reading progress, and code-copy buttons

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

No build step, package manager, or backend is required.
